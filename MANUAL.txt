AI Usage 3.7.2 — GPT + Cursor + Claude
=====================================
실행: zip을 폴더로 푼 뒤 `AI Usage.exe` 더블클릭. 없으면 `start_usage_widget.vbs`. 검은 명령 창은 위젯이 아니니 닫지 마세요.
한 번 폴더에서 실행한 뒤에는 `AI Usage.exe`만 바탕화면 등으로 복사해도 됩니다. 원래 폴더는 지우면 안 됩니다. 우클릭 → 바탕화면 바로가기 생성으로 바로가기를 만들 수 있습니다.
이미 있는 Python 3.9 이상을 먼저 사용합니다. 없거나 버전이 낮거나 Tk를 쓸 수 없을 때만 위젯용 Python을 추가로 설치합니다. 기존 Python은 업그레이드하지 않습니다.

표시 기준
- 사용 중이면 바가 굵게 유지되고 빛이 반복됩니다. 마지막 활동 후 12초가 지나면 천천히 원래 굵기로 돌아갑니다. 로컬 토큰 수는 플랜 잔여량으로 환산하지 않습니다.
- GPT 큰 숫자: 5시간 한도 잔여. 주간 한도는 아래 보조 막대. 한 줄 모드의 숫자와 색도 5시간 기준이며, 주간 등 다른 한도가 낮으면 경고 아이콘을 따로 표시합니다. 마우스를 올리면 부족한 한도와 각 잔여량을 볼 수 있습니다.
  5시간 한도가 없으면 주간을 큰 숫자로 표시합니다. 서비스가 제한 상태라고 알리면 잔여 숫자와 별개로 빨간색으로 표시.
- GPT 추가 한도: 카드 아래를 접어 그룹 단위로 표시합니다. 추가 한도 영역은 독립적으로 스크롤됩니다. 추가 한도 경고는 해당 그룹에만 적용되며 큰 숫자·한 줄 색을 바꾸지 않습니다.
- GPT 리셋권: `리셋권 1 · 10월 23일 04:58 만료`처럼 개수와 만료 시각을 함께 표시합니다. 여러 개면 가장 먼저 만료되는 것을 보여 줍니다. 개수와 만료 시각은 사용량과 같은 Codex 응답에 함께 오므로 따로 조회하지 않습니다. 만료 시각이 없으면 개수만 표시합니다. 리셋권 id나 제목은 저장하지 않습니다.
- Cursor 큰 숫자: Cursor Models 잔여. Other Models는 아래 보조 막대. 한 줄 모드도 Cursor Models 기준입니다.
- Other Models가 낮으면 해당 막대에 경고 색을 표시합니다. 큰 숫자와 한 줄 모드는 Cursor Models 기준을 유지합니다.
- Claude 큰 숫자: 대화형 Claude Code의 5시간 한도. 주간 한도는 보조 막대. 한 줄 모드도 5시간 기준입니다. 오래된 값은 마지막 값을 유지하고 소진으로 바꾸지 않습니다.
- 모든 막대는 잔여량. GPT 5시간 아래는 `19:52 리셋`처럼 시각만 표시하고 주간 아래는 `주간 리셋 9월 14일 09:00`처럼 날짜와 시각을 표시. Cursor는 청구 주기라 `9월 14일 09:00 리셋`처럼 날짜와 시각을 표시.
- 한 줄 모드: 캡슐 안에 이름+잔여%+채움. `GPT 72%`면 캡슐의 72%가 채워지고, 글자는 항상 위에 보임. 잔여량이 변하면 막대와 칩이 연속 추종하며 부드럽게 수렴합니다. 1~5%p 변화는 약 0.6~0.8초이며, 이동 중 새 값이 들어와도 끊김 없이 따라갑니다.
- 한 줄 칩 색은 카드와 같습니다. 50% 미만은 주의, 20% 미만은 임박, 5% 미만은 곧 한도입니다. Windows 알림은 10% 이하에서만 한 번 옵니다.
- 이전 데이터: 스트립·큰 숫자·칩만 회색. 마지막 성공 값이며 현재 상태를 보장하지 않음. 조회가 실패하면 그 값과 오류 원인을 카드에 남기고, 다시 확인·로그인 안내 버튼이 나타납니다.
- 카드마다 그 서비스의 마지막 확인 시각을 표시합니다. 제목 옆 시각은 켜 둔 서비스 중 가장 오래된 확인이며, 서비스마다 다르면 서비스별 확인으로 표시합니다.

조작
- 첫 실행: 표시할 GPT / Cursor / Claude를 고릅니다. 이후 우클릭 → 표시할 서비스로 다시 바꿀 수 있습니다.
- F5: 새로고침. 진행 중인 동일 서비스 요청을 중복 생성하지 않음.
- 새로고침·접기·펼치기·종료 아이콘에 마우스를 올리면 이름이 뜹니다.
- Ctrl+M / 제목 더블클릭 / 접기·펼치기 아이콘: 한 줄·상세 전환.
- 우클릭 더 크게/더 작게/기본 크기, 또는 Ctrl++ / Ctrl+- / Ctrl+0: 위젯 전체 크기 조절.
- 제목 드래그: 이동. 화면 밖으로 나가지 않게 맞추며, 작업 표시줄 바로 위에도 둘 수 있습니다.
- 서비스 제목/화살표 클릭: 해당 카드 접기·펼치기. 접어도 잔여량과 경고 배지를 표시하며 조회·알림은 계속됩니다. 접힘 상태는 재실행 시 복원합니다. Tab으로 카드를 선택하고 Enter/Space로도 전환할 수 있습니다.
- 긴 상세 화면: 헤더와 하단 상태줄은 고정되며, 본문 위에서 마우스 휠 또는 오른쪽 스크롤바로 이동합니다. PageUp/PageDown도 사용할 수 있습니다.
- 카드 본문 클릭: 해당 서비스 사용량 페이지.
- 우클릭: 표시할 서비스·로그인, 업데이트, 항상 위, 시작 실행, 한도 알림, 바탕화면 바로가기 생성, 도움말, 현재 버전, 종료.
- GPT는 Codex CLI에, Cursor는 로컬 Cursor 로그인으로 잔여량을 읽습니다. Claude는 우클릭에서 연동을 켠 뒤 로그인된 Claude Code가 필요합니다.
- Claude 제한: 지원되는 Claude Code와 Claude.ai 구독이 필요합니다. Additional/Billing은 아직 없습니다. Gemini·ChatGPT 웹 구독은 없습니다.

갱신
- GPT·Cursor는 서비스별 독립 조회. 정상 30초, 낮은 잔여 20초, 소진 5분. GPT는 로컬 토큰 활동 감지 시 요청 시작 기준 2초 간격으로 조회하며 마지막 활동 12초 후 일반 조회로 복귀합니다. Cursor는 로컬 Agent transcript 활동 또는 잔여 감소 시 요청 시작 기준 2초 간격으로 조회하며, 마지막 활동 12초 후 일반 조회로 복귀합니다.
- 연속 실패: 30초부터 최대 15분까지 점진적으로 간격 증가. 서버가 Retry-After를 주면 그 값을 따릅니다.
- Claude는 statusLine 캐시를 2초마다 읽으며, 값이 없거나 오래되면 공식 Claude CLI에 60초 간격으로 사용량만 조회합니다. 두 소스는 freshness·실제 관측 시각으로 선택하며 동률이면 statusLine을 우선합니다. CLI 값은 새 응답 없이 5분이 지나면 이전 데이터로 표시합니다.
- 직접 조회는 프롬프트를 보내지 않으므로 사용량을 소모하지 않습니다. Claude 데스크톱 앱 세션만 쓰는 경우에도 이 경로로 표시됩니다.
- statusLine은 터미널 화면에서만 실행됩니다. 터미널 세션이 열려 있으면 갱신이 2초 간격으로 빨라집니다.
- F5로 즉시 재시도 가능. 느린 요청은 다른 서비스나 UI를 막지 않음.
- 정상 값 캐시로 재시작 표시. 값이 같으면 최대 5분 간격 저장.

로그인
- Codex는 ChatGPT 데스크톱 앱이 아니라 Codex CLI 로그인이 필요합니다. Cursor는 Cursor 앱 로그인이 필요합니다.
- GPT는 설치된 Codex CLI에 공식 로컬 인터페이스(`codex app-server`)로 사용량을 물어봅니다. 위젯은 Codex 로그인 토큰을 읽지 않습니다. 위젯이 켜져 있는 동안 Codex app-server 하나를 유지하고, 위젯을 닫으면 함께 종료합니다. 사용량 읽기 외의 요청(리셋권 사용 등)은 보내지 않습니다.
- Cursor는 공개된 사용량 API가 없어, Cursor 앱이 쓰는 내부 사용량 조회를 Cursor 로그인 정보로 호출합니다. Cursor 약관상 회색지대일 수 있으니 판단해서 사용하세요. 우클릭에서 Cursor 조회를 끌 수 있습니다.
- Claude는 위젯이 계정·토큰에 접근하지 않습니다. 공식 statusLine이 남긴 값과, Claude Code 자신에게 보내는 사용량 조회만 사용합니다.
- Claude 연동을 반복하거나 연동 파일을 복구해도 처음 백업한 상태 표시 설정을 유지합니다. 복구 정보가 손상되면 원본 확인 안내가 표시됩니다.
- Claude 버전 확인과 손상 캐시 처리를 개선했습니다. 자세한 저장 항목과 복구 정책은 CLAUDE_INTEGRATION.md를 참고하세요.
- 표시할 서비스 창에서 설치·로그인을 시작할 수 있습니다. 위젯이 계정 비밀번호를 입력하지는 않습니다.
- 위젯은 기존 인증을 읽기만 하며 토큰을 갱신하거나 인증 파일을 덮어쓰지 않음.
- 로그인 변경을 자동 감지합니다. Codex auth.json은 존재·수정 시각만 확인하고 내용은 읽지 않습니다. Cursor DB는 읽기 전용으로 엽니다.
- Codex의 CODEX_HOME 환경변수가 있으면 그 위치를 사용.

업데이트
- 평소에는 업데이트 버튼이 보이지 않습니다. 배포 주소의 버전이 더 높으면 제목 옆에 초록 "↑ 업데이트 x.x.x" 버튼이 나타납니다. 새 버전이 있으면 버튼이 천천히 밝아졌다 어두워져 눈에 띄고, 마우스를 올리면 밝은 색으로 멈추며 설치 안내가 뜹니다. 한 줄 모드에서는 제목 자리에 "↑ 새 버전"으로 보입니다.
- 누르면 새 버전과 짧은 변경 요약을 보여 준 뒤 zip을 받아 위젯 폴더를 교체하고 다시 시작합니다. 로그인 설정은 %APPDATA%\AiUsageWidget 에 그대로 둡니다.

이 위젯은 OpenAI(ChatGPT·Codex)·Cursor·Anthropic과 제휴되지 않은 비공식 도구입니다. 공식 앱이 아니며, 사용량 조회는 언제든 실패하거나 바뀔 수 있습니다. 소스 라이선스는 LICENSE(MIT)입니다.
이 위젯은 사용량 조회 도구이며 크레딧 구매·리셋권 사용 기능은 없습니다.

검증: py -3 -B -m unittest discover -p "test_*.py" -v

자동 감지 / 알림
- 최신 데이터가 10% 이하 또는 소진·제한 상태가 되면 Windows 토스트를 한 번 보냅니다.
- 12%를 초과해 회복하면 다음 경고를 다시 받을 수 있습니다. 이전 데이터는 알리지 않습니다.
- 경고 상태를 저장하므로 재실행해도 같은 경고를 반복하지 않습니다.
- 우클릭: 표시할 서비스 / 한도 알림 켜기·끄기 / 알림 테스트 / GPT·Cursor 개별 조회 켜기·끄기.
- Windows 알림 끄기·집중 지원 정책은 바꾸지 않습니다. 배너가 보이지 않으면 알림 센터도 확인하세요.
- 새 PC에 수동 복사했다면 register_notifications.ps1을 실행해 알림 바로가기를 등록하세요.

안정성
- 조회가 15초를 넘으면 이전 값을 유지하고 해당 조회 프로세스를 종료합니다.
- 취소되거나 만료된 결과는 버리고, 종료 전 같은 서비스의 조회를 겹쳐 실행하지 않습니다.
- 화면 잠금·세션 연결 해제 중에는 조회를 멈추고 해제 시 다시 갱신합니다.
- 2초 간격으로 작업 영역을 확인하며 모니터 변경·화면 밖 위치를 보정합니다. 드래그 중에는 간섭하지 않습니다.
- Cursor 인증 토큰은 매 조회 프로세스에서 새로 읽습니다. 인증 파일을 쓰거나 토큰을 갱신하지 않습니다. GPT 조회가 멈추면 Codex app-server를 다시 시작합니다.
