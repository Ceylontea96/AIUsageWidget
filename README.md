# AI Usage

Windows에서 Codex·Cursor 잔여 사용량을 보는 작은 위젯입니다.

## 실행

1. [Releases](https://github.com/releases)에서 `AIUsageWidget.zip`을 받거나, 이 저장소를 받은 뒤 `start_usage_widget.vbs`를 실행합니다.
2. Python이 없으면 처음 한 번 설치를 시도합니다.
3. Codex는 Codex CLI 로그인, Cursor는 Cursor 앱 로그인이 필요합니다.

친구에게는 zip만 주면 됩니다. 새 버전이 올라가면 위젯의 **업데이트** 버튼이 켜집니다.

설정과 로그인은 `%APPDATA%\AiUsageWidget`에 저장되며 저장소에는 없습니다.
